ClusterCast v5.0.0 安装与实车验证清单（捷途 T1J 车机，无 root / 无 Shizuku）
================================================================

本版最大的变化：整个应用重写成了纯 Java 的 Gradle 工程（单 APK），
并且【摄像头全部走我们自己的 v4.7.4 栈】——EVCam 那套在这台车上黑屏，已彻底弃用。
投屏契约、车控契约、尾门单键、镜面下翻、车窗连发这些全部原样保留，一条没动。

一、这版有什么
----------------------------------------------------------------
1) 单 APK、纯 Java、零第三方库
   包名 com.ahui.clustercast，versionCode 43 / versionName 5.0.0。
   签名还是原来那把 ClusterCast 钥匙（SHA-1 8994:46:03:B3:52:01:CA:BF:D9:33:20:6B:74:D2:86:31:B8:57:4A），
   老用户直接覆盖升级，不用先卸载。
   投屏 + 车控 + 四路记录仪全部走 framework API（Camera2 / GLES20 / MediaCodec / VDBus 反射）。

2) 四路记录仪 = 我们自己的 v4.7.4 代码（关键）
   镜头 id 实测钉死：4=前、5=右、6=左、7=后，1280x800。
   四宫格单文件录像（GLES 拼接 2x2 + MediaCodec 输入面），3/5/10 分钟一段无缝切换，
   编码器 12 秒不吐帧自动重建续录，被原车 360 占用走 3 秒慢速重试。
   声音尽力而为：起不来只在日志写原因，画面照录。
   紧急锁定（加速度计，阈值默认 18m/s²）：封口当前段再移进 锁定/ 目录。
   拍照 / 四宫格一张图 / 回放 / 存储上限循环删除，全部照 4.7.4 语义。

3) 投屏页新增「探测原厂投屏」双通道按钮（v4.7.5 带来的）
   先试 ServiceManager 拿 desaysv_project_service，不通再试 bindService，
   两条都不通就把各自的真实原因写日志。它只是探测，不改动任何屏幕。

二、契约核对表（装好后照这个顺序过一遍）
----------------------------------------------------------------
A 投屏：三指左滑 → 当前前台应用上仪表；再滑换应用，上一个退回主屏不杀进程。
B 单槽：B 在仪表时，主屏点 A 只回主屏，仪表上 B 绝不被动（B→B 契约）。
C 退出：三指右滑 → 投着的退回主屏，仪表还原原显示模式，dock 还原。
D 高德：走原车导航总线通道（721699+721702），仪表跟随主屏，绝不再禁 psmap。
E 极简档：仪表上是我们自己的播放页（ClusterActivity 直接起在 display 2），
  铺没铺满以日志量出来的尺寸为准，日志说人话。
F 尾门：一个开关。蓝底白字=关闭态、红底白字=开启态；下发 327681/92（2开/1关），
  回读 ≥2 算开。
G 车窗：透气/全开/全关三个按钮，一次点击 162~165 四路批量连发（毫秒间隔），
  只发一条命令。
H 后视镜：挂 R 下翻位、退 R 回正常位（201/218 同一回路同时写），没保存过就照实说。
I 记录仪：离开页面 / 退出应用继续录（无界面格子），回来自动接回预览；
  开机自动录（可选）在服务起来 20 秒后无界面起录。
J 诚实性：所有「成功」都必须有真实回读或落盘文件支撑；失败写真实原因，绝不假成功。

三、安装
----------------------------------------------------------------
1) adb install -r ClusterCast-v5.0.0.apk     （覆盖安装即可）
2) 可选授权（一次性的，重启不失效；不授权对应功能会照实提示）：
   adb shell pm grant com.ahui.clustercast android.permission.WRITE_SECURE_SETTINGS   # 沉浸dock
   adb shell pm grant com.ahui.clustercast android.permission.PACKAGE_USAGE_STATS      # 跟随前台
   adb shell cmd notification allow_listener com.ahui.clustercast/.MusicListener       # 仪表歌词
3) 打开应用 → 点「启动服务」→ 弹一次 CAMERA 授权（记录仪用）→ 上滑退出设置页。
   三指左滑即投屏。

四、这版验证过的编译面
----------------------------------------------------------------
- 26 个 Java 源文件全部对 android-36 SDK 单编通过（javac --release 11，无告警级错误）。
- Gradle 9.1.0 / AGP 9.0.0 assembleRelease 成功；aapt 确认包名/版本/权限与清单一致；
  apksigner 确认签名 SHA-1 与老版本一致（可覆盖升级）。
- dex 内关键契约字符串（手势 action、尾门/挡位日志、无缝换段、紧急锁定、
  原厂投屏双通道探测）逐条核对在位。

源码在 zip 的 src/ 目录：Gradle 工程原样（settings.gradle.kts + app/），
cd 进去 ./gradlew :app:assembleRelease --offline 就能复现这个 APK。
